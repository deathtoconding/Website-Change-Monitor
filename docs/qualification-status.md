## Validation boundaries

Local static checks and database-independent tests can run in the development workspace. Docker, PostgreSQL, and Redis were not available locally for this session, so service-backed integration, Compose, and browser E2E results must come from GitHub Actions. Those jobs are required qualification gates; skipped integration tests do not count as passing results.

The deployment-only gates require a real staging or production environment and must not be inferred from CI, a local fixture, or placeholder URLs. No Stripe or Resend credentials are committed or fabricated. Optional provider checks run only when their corresponding legitimate GitHub Secrets are configured; the Resend recipient must be controlled by the repository owner.
